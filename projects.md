# Projects

## Project 1: AttendX Pro — QR/Barcode Attendance System
- **Problem:** Taking attendance manually in class is slow and prone to proxy marking and errors.
- **Solution:** A web-based attendance system where students are marked present by scanning a QR code or barcode, hosted on GitHub Pages.
- **Technologies:** HTML, CSS, JavaScript, GitHub Pages
- **My contribution:** Designed and built the full system, including the scanning flow and the attendance records view.
- **Possible improvement:** Add location or time-window checks to prevent proxy attendance and export reports to Excel.

## Project 2: Jarvis — Offline AI Automation Agent
- **Problem:** Cloud AI assistants need internet access and send personal data to external servers.
- **Solution:** A fully offline ReAct-style agent that runs a local LLM through Ollama and automates tasks on my own computer.
- **Technologies:** Python, Ollama, Local LLMs, Linux scripting
- **My contribution:** Wrote the agent loop, the tool-calling logic and the local model integration.
- **Possible improvement:** Add voice input and a safety confirmation step before running system commands.
